 ----- Patches to bugs in the EF mod -----

[X] 1. (artemis.ini) Fix torpedoTubeLoadingCoef typo, which made tubes never load

[X] 2. (vesseldata.xml) Fixed Ventacon taunt immunity not being deducible from science info. Their 3 taunts are now about drunk crew, marine biology, and pirates.

[X] 3. (vesseldata.xml) Retired TSN ship efficiencies are now 10% worse than vanilla (before, they were a 10% improvement)

[X] 4. (vesseldata.xml) Fixed Advanced Longbow shield strength - Set to 80/60 to better match the standard longbow's 60/60 (before, they were a measly 20/15)

 ----- Patches to bugs in vanilla 2.8 -----

[X] 5. (Artemis.exe) Made more resistant to memory-related crashes, by flipping a single bit that makes it handle larger amounts of memory being allocated (LargeAddressAware). Put together by Starry.

[X] 6. (controls.ini) Fix weapons keybind K being used for both target previous and raise shields; rebound select previous to N

[X] 7. (controls.ini) Fix weapons keybinds 7,8,9, and 0 being used for both load/unload tubes and selecting ordinance type; rebound load/unload tubes to nothing

 ----- Non-functional/technical changes -----

[X] 8. (artemis.ini) - Undid a lot of unnecessary edits to the order of the settings, comments, and whitespace. Now the file much more closely matches the vanilla 2.8 version.
